# 机甲战棋（试作版）

一个在浏览器里运行的机甲战棋原型：超级机器人大战式的战棋，加上朝向夹击、破防、视线、体积、分波刷敌，以及一个参考《明日方舟》集成战略的**肉鸽模式**。

> ⚠️ **非官方、非商业的个人试作。** 目前借用了《机动战士高达》系列、《全金属狂潮》、《超级机器人大战 OG》等作品的角色名和设定，版权归各自权利人所有；这些只用于朋友间试玩，正式版会全部替换成原创内容。本仓库**不附带开源许可证**。

## 怎么玩

1. 下载 [`Claude hand off/src/index.html`](Claude%20hand%20off/src/index.html)（打开后点右上角的下载按钮），或者点仓库页面上的 **Code → Download ZIP** 下载整个仓库、解压后打开根目录的 `index.html`。
2. 双击用浏览器打开就能玩，**不用安装、不用联网**。推荐 Chrome 或 Edge。
3. 一打开就是**肉鸽模式**（推荐）。左上角「关卡」还可以选**机体展示**（每台机体一关，按势力分组）和**剧情模式**（待施工，目前放着教学关、防卫战、自由对战等原型关卡）。肉鸽打到一半切去别的模式，切回来会接着打。

常用操作：空格（选中 / 原地行动 / 选推荐目标 / 确认，一路按空格相当于半自动战斗），Tab 切换机体，Esc 撤回，攻击前 WASD 改朝向，M 键静音。

## 试玩反馈（请走 Issues）

打完一局肉鸽后：

1. 在肉鸽大地图上点「**游玩记录**」→「**下载**」，得到一个记录文件；
2. 到本仓库 **Issues → New issue → 试玩反馈**，把记录文件拖进去，写几句感受（哪关太难 / 太简单、哪个角色不好用、哪里卡住了）。

提到具体关卡时请带上关卡编号，例如 `ISW-1-N-7`（显示在关卡名前面）。

## 仓库结构（给开发者）

| 路径 | 内容 |
|---|---|
| `Claude hand off/src/` | 游戏本体。`artifact-fragment.html` 是唯一可编辑的源文件，`index.html` 由 `node tools/build-src.mjs` 生成 |
| `Claude hand off/docs/` | 设计文档：规则、教学关、游戏模式、肉鸽设计、肉鸽关卡表、角色与敌人一览 |
| `Claude hand off/tests/` | Playwright 浏览器测试 |
| `Claude hand off/HANDOFF.md` | 开发交接说明（读这个上手） |
| `art/` | 机体图标矢量素材（原创） |
| `audio/` | 乐谱与播放层（原创，Web Audio 现场合成） |
| `tools/` | 素材渲染、自检、冒烟测试、两份 HTML 的同步脚本 |
| `协作/` | 两个开发 agent（Claude / DSH）之间的协作日志、任务板、接口约定 |

开发由作者主导，Claude（规则 / 数据 / 肉鸽 / 测试）和 DSH（美术 / 音乐 / 工具）协作完成。
