## 二、代码约定
- **新公式**：伤害 =（威力 − 装甲）×（1 +（攻击 − 防御）/ 100）。重写过的角色登记在 `04` 的 **`NEW_FORMULA`** 和 `30b` 的 **`NEW_POWER`**（不再乘旧倍率、不再换算）；单把重写的武器写 `v37:true`。还没重写的只剩**影世界的 B2**。`TIER_FLOOR` 现在只剩 `B2`。
- **参照点**（`04` 里 `NEW_FORMULA` 上面的注释有完整说明）：普通武器 Lv10 打 Lv2 量产机，精锐主武器约 6000、骨干约 4500、普通 ≈ 同职业演习兵；Lv20 大招打 Lv12 盾卫，骨干约 10000、精锐约 12000；`statMul` Lv20 ×1.2 / Lv30 ×1.5；觉醒系大招用「属性 + 觉醒」。
- **角色机制放 `src/js/17b-角色机制.js`**（角色对话的文件）：特技 / 被动的钩子、只给个别角色用的武器效果、测试接口 `window.__chars`（`__game` 归规则对话）。
- **规则文件可以直接改**（作者 10-08 定），但每次都要写进 `协作/角色对话→规则交接.md`（表格：文件 / 改了什么 / 为什么），规则对话会回复。
- 档位在 `22` 的 `TIER`；晋升被动在 `03` 的 `PROMO_PASSIVE`；特技说明在 `03` 的 `ABIL`、效果在 `TRAIT_FX`；试炼提示在 `06` 的 `TRIALS`。
- 武器新字段（这一轮加的）：`taOnly / taMove`（TRANS-AM）、`evadeCd`（赌徒的直觉）、`smoke`、`slow`、`awakenAdd / awakenSeed`、`seedIff`、`summon`（召唤物）、`bounce`（连锁弹跳）、`chain / chainStep`（连射）、`shape:'box' + size`（选区域地图炮）、`hitsMax`（多段段数随机）、`lockHits / lockStep / markOnHit`（锁定 + 多段）、`skillPick`（模板：只能带一个技能）。

## 三、工作流
1. `git pull --rebase origin main` → 改 `Claude hand off/src/js/` → `node tools/build-src.mjs`；
2. 测试（云端）：`cd "Claude hand off/tests"; NODE_PATH=/opt/npm-tools/node_modules node X.js`。每个势力一份测试，改完至少跑本势力 + `formula / class_mech / startcd / rule_stages`；`trials_run.js` 的机器人不会用新机制（TRANS-AM、烟雾等），打不完不代表太难；
3. `GAME_VERSION`（`31b`）+0.0.1，提交说明开头 `[角色]`，`git push`；
4. 文档：《任务板》角色一栏、《角色与敌人一览》（现在按版本往后加小节，第十六节为止；第二节的旧数据只对还没重写的势力有效）、《角色对话→规则交接》，仓库和项目文档两边同步；
5. 试玩页：按《分工与派活指南》第 1.5 节第 5 条（**发布包现在还带音乐文件，以那里的最新说明为准**）；先 `read` 再发布，**不传 capabilities**；发布被拒说明有更新的版本，按提示读了以后重新发布。

## 四、小技巧
- 想看一批武器的参照伤害，可以写个小脚本：Playwright 打开 fragment，`__game.makeUnit` + `levelUp` 造单位，`__game.damageCalc / forecast` 算（这一轮用过很多次）。
- 每个势力开工前先问作者几个关键问题（档位、谁是精锐、机制边界），作者答完再一次性实现，比边做边改省。
