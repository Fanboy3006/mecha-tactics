# 分叉项目设计方案：自动战斗 RPG（暂名「机甲指挥」）

> 统筹对话 2026-10-10 写，交给 DSH 实施。作者的出发点：战棋的关卡设计（尤其肉鸽随机关卡）太难；美术和音乐大部分能搬过去。
> 原则：**战斗改成自动进行，玩家每回合只给大方向的指令**；角色、数值、肉鸽外壳、美术、音乐尽量原样复用。
> 战棋项目（mecha-tactics）冻结保留，不删、不改；它的测试版 / 正式版链接继续能玩。

## 1. 一句话
玩家在肉鸽大地图上走格子、招募机师、拿藏品；遇到战斗时，把最多 6 台机体摆进**前排 / 后排**，每回合开始给每台机体下一个**指令**（集火、守护、防御……），然后这一回合**自动打完**，看结果，再下下一回合的指令。

## 3. 战场

### 3.1 站位
- 双方各有 **2 排 × 3 列 = 6 个位置**：前排（靠近敌人）、后排。列号 0–2。
- 出击上限沿用肉鸽的 `deployCap()`，最多 6。
- 战前「编队」画面：把出击机体拖进 6 个格子。默认摆法：重装、近卫放前排；狙击、指挥放后排；尖兵、特种放前排空位，满了放后排。
- 前排全灭后，后排**不会**自动前移（后排因此变得容易被近战打到，见 3.3）。

### 3.2 回合
1. **指令阶段**：显示每个敌人的**意图**（下一个行动要打谁、用什么，见 5.3）；玩家给每台机体选指令（第 4 节）。指令保留到玩家改掉为止，所以不想改可以直接点「开打」。
2. **行动阶段**：全场单位按**速度**从高到低各行动一次（速度相同时我方先，再按列号）；自动播放，可以暂停、二倍速、跳过动画。
3. 回合结束：buff / 冷却计时减 1。
- **速度** = 机动（模板的 `mov`）× 10 + 闪避 ÷ 2，取整。（尖兵快、重装慢；数值以后再调）
- 胜负：敌方全灭 = 胜；我方全灭 = 败；**第 12 回合结束还没分出胜负 = 败**（按「撤退」处理，扣作战耐久，和战棋肉鸽一样）。

### 3.3 射程换成「能打到哪一排」
按武器的 `fire` 换算，换算写成一个函数，**不要手改每把武器**：

| 战棋的 fire | 新类型 | 能打谁 |
|---|---|---|
| `melee` | 近战 | 只能打敌方**前排**；前排没人了才能打后排 |
| `direct` | 直射 | 任意目标；打后排时如果敌方前排还有人，命中 −20（被挡） |
| `indirect` | 曲射 | 任意目标，没有惩罚 |
| `map`、`support`（伤害类） | 范围 | 按武器新加的 `area` 字段：`row`（一整排）、`col`（一整列）、`cross`（目标和它上下左右相邻格）、`all`（全体）。没写 `area` 的默认 `row` |
| `heal` | 修理 | 我方任意一台，优先 HP 比例最低的 |
| `passive`、`device` | 第一期不做（见 6.2） | |

- 战棋里的 `range` 只用来判断类型，数值不再用；`afterMove` 等移动相关字段忽略。

## 4. 指令（每台机体每回合一个）

| 指令 | 效果 |
|---|---|
| **进攻**（默认） | AI 自己挑目标和武器（规则见 5.1） |
| **集火 ▶ 目标** | 玩家点一个敌人；这台机体只要打得到就打它，打不到（近战打不到后排）就按「进攻」处理 |
| **守护 ▶ 队友** | 本回合内，打这名队友的**单体**攻击改打守护者（守护者按「防御」结算伤害）；守护者本回合自己照常攻击，但伤害 −30%。一名队友同时只能被一人守护 |
| **防御** | 不攻击；本回合受到的伤害按防御值 +50 计算（和战棋的防御姿态一样）；下回合开始回复 5% 最大 HP |
| **换位** | 和同一列另一排的位置交换（对面是空位就直接移过去）；本回合不攻击 |

**大招开关**：每台机体旁边一个开关「大招：自动 / 保留」。自动 = 冷却好了就放；保留 = 不放，等玩家改回自动。（大招 = 战棋里 `unlock` 为 20 或 30 的武器，有开场冷却 3 回合。）

> 深度主要来自：看到敌人意图后用「守护 / 防御」挡关键一击；用「集火」抢在敌人大招前击破；控制大招时机。

## 5. 自动行为（AI）

### 5.1 我方「进攻」怎么挑
1. 武器：能用的武器里，按「对目标的期望伤害」最大的选（期望伤害 = 命中率 × 伤害，暴击按 1 + 暴击率 计）；大招开关为「自动」且冷却好时，大招优先。
2. 目标：期望伤害能击破的目标优先（多个时打 HP 最高的那个，不浪费）；没有能击破的，打「期望伤害 ÷ 目标当前 HP」最大的。
3. 范围武器：按命中的敌人总期望伤害挑落点。

### 5.2 敌方
- 普通敌人：同 5.1；近战敌人优先打我方前排血最少的。
- 职业倾向（敌人模板的 `tags.战斗分类` 或按武器推断）：狙击类优先打后排；有 `overwatch` 的敌人改成「第一个行动的我方单位会被它先打一下」（替代压制射击）。
- Boss：各写一个简单脚本（每 N 回合放一次大技能、半血换阶段），第一期只做蓝色大肥鱼一个。

### 5.3 意图显示
- 指令阶段开始时，先按 5.2 算出每个敌人**这一回合**打算打谁、用哪把武器，显示在敌人头上（图标 + 预计伤害）。
- 行动阶段敌人**照着意图打**；如果目标已经倒下或者被守护，就按规则改打（守护）或重新挑（目标倒下）。

## 6. 数值和特技

### 6.1 公式（照搬战棋 v0.42）
- 伤害 =（威力 − 装甲）× `statCoef`（攻击能力值 − 防御值），命中后最少 10；暴击威力 ×2。代码从战棋 `15-战斗计算.js` 复制 `statCoef / atkStat / statVal / effArmor` 和 `dmgCore` 的数值部分（去掉朝向、地形、区域相关的项）。
- 命中 = 武器命中 +（精准 − 160）÷ 2 − 目标闪避，再加 3.3 的「被挡 −20」，限制在 0–100。精准沿用战棋的 `AIM_BY_CLASS`。
- 暴击率 = 10% + 武器修正。
- **反击取消**（自动战斗里反击会让节奏很乱）。以后要的话做成特技。
- 随机数一律用**带种子的随机数**（同一种子同一结果），测试和复盘都要用。

### 6.2 特技和特殊武器（第一期的处理）
战棋里很多特技和特殊武器依赖格子（传送、推开、布墙、冲刺……）。**第一期不做任何特技**，只做：
- 普通伤害武器（含多段 `hits`、`statMul`、`dmgType`、`ignoreDef`、`noCounter`）；
- 修理类；
- 能量屏障、λ 力场、护盾（数值类，照搬）。

每个角色的特技、特殊武器（`special` 字段）先在角色卡上显示「（自动战斗版待设计）」，并且全部列进一份表 `docs/特技换算待办.md`（角色、特技名、战棋里的效果、为什么不能直接搬）。**换算方案由 Claude 设计**，DSH 不要自己编。

### 6.3 职业的自动战斗特色（第一期就做，简单版）
| 职业 | 特色 |
|---|---|
| 重装 | 在前排时，敌方单体攻击 50% 概率改打它（嘲讽） |
| 近卫 | 击破目标后立刻再行动一次（每回合最多 1 次） |
| 尖兵 | 每回合第一次被攻击时闪避 +20 |
| 狙击 | 打后排没有「被挡 −20」；暴击率 +10% |
| 指挥 | 回合开始时，同一排的队友命中 +10（本回合） |
| 特种 | 武器命中时目标防御值 −20，持续到下回合结束（不叠加） |

## 7. 肉鸽外壳
- 复制战棋的 `26-地图生成 / 27-开局 / 28-层 / 29-渲染 / 30-移动与节点` 和招募券、希望、藏品框架、存档；节点里的「战斗 / 精英 / Boss」改成进入自动战斗。
- **敌人编成表**（取代战棋的关卡和地图）：`src/js/编成.js`，每层一张表，每条 = 一组敌人和站位，例如
  `{层:1, 类型:'普通', 前:['hound','hound'], 后:['drone']}`。战斗节点从对应层、对应类型里随机抽一条。第一期每层每种类型 3 条即可，敌人等级沿用 `runEnemyLv`，强度沿用 `ENEMY_SCALE`。
- 藏品：只带纯数值类的（加 HP、加伤害、加命中……）；涉及格子 / 移动的先禁用，列进 `docs/特技换算待办.md`。
- 零件：只带大地图上用的（推进剂、飞行之类），战斗里的先禁用。
- 侵蚀场：第一期不做。

## 8. 界面和资源

### 8.1 画面
1. 开场菜单（继续存档 / 新的一局 / 音乐鉴赏 / 游玩记录）；
2. 选分队 → 大地图（照搬）；
3. **编队**：左边队伍列表，右边 2×3 格子，拖进去；显示每台的速度和大招冷却；
4. **战斗**：左右（或上下）两边各 2×3，机体用 `MI` 图标 / 像素精灵；头上血条、护盾条、意图标记；下方指令面板（选中机体 → 点指令 → 需要目标的再点目标）；右边战斗记录；顶上回合数、「开打」「暂停」「二倍速」「跳过动画」；
5. 结算：胜负、奖励（照搬肉鸽）。
- 动画：攻击者向前冲一下、受击闪白、飘伤害数字（暴击大字），每次行动 0.5 秒左右；二倍速 / 跳过动画只影响播放，不影响结果。
- 手机宽度也要能玩（格子缩小，指令面板换到底部）。

### 8.2 资源怎么搬
- `art/mech-icons.js` 整个复制，`build-src.mjs` 照战棋的方式注入；用 `MI.draw(ctx, MI.build(id, ...), size, x, y)` 或 `MI.makeSprite` 画；机体对应图标用战棋的 `ICON_BY_MECH`、势力调色板 `FACTION_PAL`。
- 像素精灵：复制 `art/pixel/` 和 PIXEL 注入块。
- 音乐：复制 `audio/local-music.js`、`audio/music-room.js`、`audio/SUNO/`；场景对应：开场菜单 = title，大地图 / 编队 = mapStrategy，战斗中 = allyPhase（敌方行动时不切曲子，避免一回合切两次），Boss 战 = boss；**放大招时切主题曲，保持到本回合结束**（和战棋一样）。
- `audio/` 根目录的版权 mp3、`图片库/` **绝不复制进新仓库**。
