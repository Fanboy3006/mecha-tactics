## #5 ds_code 小修 ☑（DeepSeek 自己改的，Claude 审过；971820d）
第一次实战（#2）发现三个问题：
1. **换行符**：Aider 在 Windows 上把整个文件写成 CRLF，一处改动变成整文件 800 多行的假改动（仓库 `.gitattributes` 是 `* -text`，git 不会帮忙转）。请给 aider 加 `--line-endings lf`；保险起见，ds_code 在 aider 结束后把改动过的文件统一转成 LF。
2. **构建**：Aider 只会「建议」跑 `build-src`，不会真跑，提交里 fragment / index.html 没更新。请在 ds_code 里：aider 结束后自动跑 `node tools/build-src.mjs`（不是 `--check`），有变化就 `git commit --amend --no-edit` 并入同一个提交。
3. **测试**：本机没装 Playwright（`test` 参数跑起来报 `Cannot find module 'playwright'`）。请在 `C:\DSH-机战` 装上（`npm i playwright` + `npx playwright install chromium`），或者在返回里明确写「本机没法跑浏览器测试」。
4. **关掉 Aider 的自动 lint**（`--no-auto-lint`，#3 出事的原因）；并在任务前面固定加一句：「src/js 里每个文件只是同一个 `<script>` 的一段，括号不配对是正常的，不要修」。
5. 可选：加一个 `ds_sync()` 工具做 `git pull --ff-only` + `git push`，现在 Claude 是用 `/run git pull` 绕的。

**结果**：`--line-endings lf`、`--no-auto-lint`、任务前固定提醒（PREAMBLE）、aider 结束后统一 LF + 跑 `build-src` + 并入同一提交。Playwright 已装在 `Claude hand off/tests/node_modules`（不进仓库），`test` 参数现在能跑浏览器测试（`class_mech.js` 实测通过）。**改动要在桌面版重启后才生效。** `ds_sync` 没做，继续用 `/run git pull` / `git push`。
