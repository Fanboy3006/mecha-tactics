# 接口约定（游戏 ↔ 美术 / 音乐 / 工具）

改这里列出的任何字段或函数，**先在本文件登记，再在日志里提一句**。

## 1. 单位对象上，绘制层可以读的字段
| 字段 | 含义 |
|---|---|
| `u.side` | `'ally'` / `'enemy'` / `'neutral'` |
| `u.mech` | 机体代号（我方如 `U7`，敌方是中文机体名如 `重型坦克`）。`ICON_BY_MECH` 用它查图标 |
| `u.tags.势力` | 影世界 / 月球王国 / 天人 / 克莱因派 / 预防者 / ATX / 秘银（v0.26 起原「米斯里尔」改名） |
| `u.tags.战斗分类` | 近卫 / 尖兵 / 辅助 / 重装 / 狙击 / 特种（v0.17 起没有「医疗」） |
| `u.w`, `u.h` | 占地格数（1 / 2 / 3） |
| `u.flying` | 当前是否在空中 |
| `u.facing` | `'up'` / `'down'` / `'left'` / `'right'` |
| `u.acted` | 本回合已行动 → 灰调 |
| `u.hp` / `u.maxHp` | 生命值 |
| `u.shield` / `u.shieldHp` | **护盾上限 / 当前护盾值**。光罩和护盾条用 `shieldHp`；己方阶段开始时回满 |
| `u.awakened` | U7 的 λ 觉醒状态（以后可以给它单独的特效） |
| `hasStealth(u)` | 是否隐身（函数，不是字段） → 半透明 |
| `u.transformed` / `u.transform` | 变身；图标写在 `FORMS[形态].icon` |
| `u.stunned` | 被骇入 |
| `u.debuffs` / `breakSum(u)` | 破防层数 |
| `u.badgeList` | （预留）`[{color, glyph}]` → 头顶徽记 |
| `u.hidden` | （预留）强制半透明 |

## 2. 图标查找顺序（`iconIdOf(u)`）
中立 → `debris`；变身 → `FORMS[...].icon`；`ICON_BY_MECH[u.mech]`；都没有 → `stockIcon(u)`（借用同分类原型）。

## 3. 给工具用的 `window.__game`
`templates`（`{allies, enemies, forms, debris}`）、`art`（MechIcons）、`unitSprite(u)`、`iconIdOf(u)`、`levels`、`units`、`S`、`onTile`、`startLevel`……完整列表见 HANDOFF 第 8 节。
**注意**：`__game.roster` 是肉鸽 / 编队的玩家部队，不是单位模板。

## 4. 音频接入（DSH 交付 v0.19，Claude 接线 v0.20）

`MechAudio` 已由 `tools/build-src.mjs` 注入游戏（和 `MechIcons` 一样是 UMD，挂在 `globalThis` 上），
源文件 `audio/mech-audio.js`；乐谱数据 `audio/score.js` 也一起注入，**两者都必须注入且顺序为 score → audio**。

游戏里直接调：

```js
MechAudio.play('allyPhase');   // 切 BGM，交叉淡入 0.9s。返回 bool
MechAudio.sfx('hit');          // 播放音效。返回 bool
MechAudio.setVolume(0.7, 0.8); // bgm / sfx，各 0..1
MechAudio.mute(true);
MechAudio.unlock();            // 浏览器要求用户手势后才能出声，第一次点击时调一次
MechAudio.state();             // {ready, cue, muted, bgm, sfx, playing}，调试用
MechAudio.stop();              // 停 BGM
```

**行为约定（接线时要知道）**
- `play(id)` 传同一个 id 时**不会重头播**（避免每个阶段都重启同一首）；传新 id 才交叉淡入切换。
- `victory` / `defeat` **不循环**，放完自动停；其余循环。
- 没有 `AudioContext`（旧浏览器）或没解锁时，所有调用**返回 false 且不抛异常** —— 接线时不用包 try。
- 浏览器**必须**在用户第一次点击/按键之后才能出声。`MechAudio` 已经自动挂了一次性监听，
  但 Claude 在「开始游戏」按钮里显式调一次 `unlock()` 更稳。
- 音色是**算法合成器**（不是采样音源），和离线渲染的 `audio/out/*.wav` 不完全一样；
  想听音符本身请听 `audio/out/*.mid`。

**cue 一览**

| 时刻 | cue |
|---|---|
| 进入标题 / 关卡选择 | `title` |
| 肉鸽大地图 | `mapStrategy` |
| 我方阶段开始 | `allyPhase` |
| 敌方阶段开始 | `enemyPhase` |
| 场上有 Boss（`ENEMY_BOSS`）或终点关 | `boss` |
| 胜利 / 失败结算 | `victory` / `defeat` |
| （试听用，游戏里不用） | `demoBattle` |

**音效名（DSH 定的，Claude 直接用）**

| 名字 | 建议触发时机 |
|---|---|
| `hit` | 攻击命中 |
| `miss` | 攻击未中（掠过） |
| `crit` | 暴击 |
| `destroy` | 击破 |
| `shield` | 护盾吸收（`shieldHp` 挡下伤害时） |
| `lambda` | U7 的 λ 觉醒 |
| `heal` | 修理 / 回复 |
| `ui` | 界面点击、切换 |
| `warn` | 回合上限倒数、陨石预警 |

试听页：`audio/preview.html`（双击打开，一键听全部曲目和音效）。
自检：`node tools/check-audio.mjs`（音高/时间/音域/接口一致性；**验不了好不好听**）。

**游戏侧接线（v0.20，Claude）**：代码在 fragment 的「音频接线」一节。
- 场景 → cue：`menu`（编队 / 肉鸽开局）→ `title`，`map` → `mapStrategy`，`battle` → 按阶段 / Boss 判定；
- 音效的触发位置：`strikeResolved` 钩子（新增 `crit` 字段）、`unitDestroyed` 钩子、护盾减免步骤、`shieldBroken`、`addFloat`（绿色 `+` 开头）、`orderMeteor`、回合上限、按钮点击；
- 静音状态存在 localStorage 的 `mecha-tactics-sound`（`'on'` / `'off'`）；
- `window.__game.sound` → `{on, scene, cue}`。

## 5. 通用约定
- **不要用浏览器自带的 `alert` / `confirm` / `prompt`**：claude.ai 页面和桌面应用会拦截它们（`confirm` 直接返回 false），按钮会像没反应一样。
  - 要确认：用 `await ask(标题, 说明, 确认按钮文字)`，返回 true / false；
  - 要提示或做选择：用 `await dlg(html)`，按钮写 `data-v="值"`，返回被点按钮的值。
  - v0.21 修过一次（撤退 / 放弃本局 / 遣散 / 清空记录），测试见 `tests/run_quit.js`。
