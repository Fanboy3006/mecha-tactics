作战记录

    当前规则 v0.30
    • 距离和射程一律按菱形计算（只算横竖步数）。
    • 命中 = 武器命中 −（闪避 + 地形闪避）；选择回避时命中减半。
    • 暴击率 = 10% + 武器修正 + 朝向修正；暴击伤害 ×1.2。地图炮和被动技能不暴击、不判朝向。
    • 个人特技：雷萨「门之力」、蕾卡「游刃有余」（剩余移动力每点闪避 +5）、Feena「月光共鸣」（不能主动攻击，行动结束自动释放最高序号武器）、阿布拉德「不动如山」、Iris「战地急救」、洛克昂「狙い撃つぜ」（溢出命中转暴击）。
    • 指挥官（剧情模式）：战前编队可以指定 Feena 为指挥官（不出场）。指挥技能【陨石召唤】：指定 3×3，2 回合后落下 7999 物理伤害（敌我都打），空格生成 HP1000 残骸，冷却 3 回合。
    • Esc：选中机体时撤回这台机体本次所有未完成的行动（移动、朝向、起飞落地）并取消选中；传送、变身、额外攻击这类已发生的行动无法撤回，此时 Esc 按待机处理。
    • 快捷键：没有选中机体时 Tab / Shift+Tab = 在未行动的机体之间切换光标，空格 = 选中光标所在（或下一台未行动）的机体，全部行动完后空格 = 询问是否结束回合（再按空格确认）；选中机体后空格 = 原地行动；移动后 W/A/S/D = 改朝向（上 / 左 / 下 / 右）；移动后空格 = 攻击（自动高亮可攻击的敌人并预选推荐目标，再按空格选中它，Tab 切换预选）或待机；预测里空格 = 确认攻击；Esc = 返回。
    • 起飞 / 落地要在移动前决定。个人特技 Lv10 解锁。
    • 近卫（刹那·CB1 能天使）：「连斩」击破后可原地再攻击一次，每回合最多 1 次（Lv30 起 2 次）；特技「我就是高达」每个相邻敌机命中、闪避各 +10（最多 +30）。
    • 特种（阿雷路亚）：GN 冲撞把目标推开 2 格，撞到东西双方各受 800，推进裂谷直接坠毁。
    • 特种（提耶利亚）：脱装变身纳德雷，外装甲在 3 格内化为 3 格宽的 GN 墙（挡移动和所有直射，持续 2 回合），本体换装近身武器；单向，一场一次。
    • 闪避疲劳（蕾卡）：同一回合内每完全闪避一次攻击，闪避 −10，下一个我方阶段开始时恢复。
    • 破防：只由标记类技能（TRANS-AM 狙击、火控锁定）附加，目标所有防御按比例下降，到下一个我方阶段开始清除。侧击 / 背击不再附加破防。
    • 朝向：正面 +0 / 侧面 目标闪避−10 暴击+10 无视25%装甲 / 背面 目标闪避−20 暴击+25 无视50%装甲（只对这一击生效）。攻击时自动转向目标，被攻击后转向攻击者（可以夹击）。援护一律按正面。
    • 伤害生成 = 威力 + 格斗或射击 × 5（暂定）。
    • 减免顺序：① 无效化（能量屏障）→ ② 百分比（地形、防御 −50%、抗性、减伤）→ ③ 装甲（扣完最低 10）、λ 力场 → ④ 护盾值。带「无视防御」的武器跳过全部减免（连护盾也无视）；特殊伤害只经过护盾类（屏障 / λ 力场 / 护盾值）。
    • 直射：中间有敌方单位或山地就不能打；但目标在空中时，地面的山和单位都不挡，只有空中的大型敌方单位会挡。曲射：无视阻挡，有最小射程。近战不看视线。
    • 武器按 CD 和次数计算，没有标注的就是 0 CD、无限次数。
    • 除影凤凰外，武器都可以移动后使用（月光祝福也可以）。地图炮必中、不能被反击，影凤凰也会打到友军。
    • 伤害类型：物理 / 光束 / 特殊。敌人对物理、光束有不同的弱点 / 抗性；特殊伤害除了护盾什么都不吃。弱点还可以针对近战 / 直射 / 曲射 / 范围 / 背面 / 暴击 / 多段 / 反击。
    • 浮游炮：16 段，每段从 8 个随机方向攻击，目标闪避减半，不附加破防。多重锁定：一次选多个目标，不能被反击。
    • 出击上限：防卫战 10 台、弱点演习 8 台、自由对战 8 台；另可选 1 位指挥官（不出场）。角色试炼：每个角色一关，Lv20。
    • 月光祝福：友军闪避 +15、命中 +15，到下一个我方阶段开始失效。
    • 援护防御（阿布拉德）：敌方阶段相邻友军被攻击时可代为承受并自动防御，每个敌方阶段 2 次。
    • 螺旋式打桩机：10 段判定，首段命中 85，命中 −10 / 未中 +10，每段无视一切减免。
    • 修理装置：回复 3000 × 射击÷100。月华再生：Iris 行动结束后 5 格内友军回复 10% 最大 HP。
    • 残月的余响：Feena 我方阶段行动结束后自动释放；4 格内的月球王国队友按自身最大射程延伸范围，不能接力。
    • 友军可穿过不可停留；敌军不可穿过；无控制区。飞行单位移动消耗恒为 1，不吃地形加成。
    • 单位标签（势力 / 远近分类 / 战斗分类）目前只做展示，留给以后肉鸽的羁绊和筛选用。
    • 胜利条件：全歼敌军。出击即升 1 级（HP +200，格斗 / 射击 / 技量 +2）。
