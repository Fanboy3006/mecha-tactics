# 游戏模式设计（框架 v0.1）

本作分为**剧情模式**和**肉鸽模式**，两种模式共用同一套战斗规则（见《战棋规则设计》），但成长、奖惩和难度完全分开设计。

## 〇、入口与模式划分（v0.23）
**v0.29 起打开游戏先显示「选择模式」**：★ 肉鸽模式（推荐，橙色主按钮）/ 教学关 / 剧情模式（待施工，点进去可以选原型关卡：防卫战、弱点演习、自由对战）。之后随时可以在顶栏「关卡」菜单里切换。

游戏里的「关卡」下拉菜单分三大类，**默认入口是肉鸽模式**：

| 分类 | 内容 | 状态 |
|---|---|---|
| ★ 肉鸽模式（推荐） | 混沌迷宫，见第二节 | 主要玩法，持续开发中 |
| 剧情模式 | 剧本还没写；目前放着原型关卡：教学 1–3、大规模防卫战、弱点演习、自由对战 | **待施工** |
| 机体展示 | 每台机体一关（Lv20，敌人 Lv1），按势力分组 | 可玩 |
| 工具 · 关卡编辑器（v0.27） | 手动微调肉鸽关和原型关：地形、敌人、波次、出击点；可试打；「导出全部改动」交给 Claude 写进游戏 | 可用 |

- 肉鸽进行中切到别的模式，局内进度一直保留；切回「肉鸽模式」时：
  - 在大地图上切走的，回到大地图；
  - 在作战中切走的，回到**同一战、同一回合**，接着打。
- 肉鸽的对话框（编队、事件、商店、战后结算等）开着时不能切换模式，先处理完再切。
- 刷新页面会丢掉进行中的肉鸽（还没做存档）。

## 一、剧情模式

**定位**：通关难度较低，主要目的是让玩家熟悉每个角色的特点和打法。教学关就是剧情模式的前几关。

- **等级**：保留传统的等级成长（目前测试版是 Lv1 起步，Lv20 解锁大招，Lv30 大招强化）。
- **成长来源**：作战后获得经验和奖励。具体的经验规则待定；目前测试版是"出击即升 1 级"。
- **机体被击破的惩罚**：**降低作战后奖励**。不会直接失败，除非关卡另有规定，例如教学 1 规定指定单位被击破即失败。
- **难度**：
  - 关卡设计以"展示角色特点"为主，正确使用角色能力就能比较轻松地过关；
  - 每关聚焦一两个机制，由教学提示引导。
- **指挥官**（剧情模式专属）：
  - 战前编队时，可以把一位有指挥技能的角色指定为指挥官（最多一位）；
  - 指挥官**不出场**，不能作为机师作战；
  - 指挥官在我方阶段的空闲时刻下达指挥技能，不占用任何机体的行动；
  - 目前只设计了 **Feena** 一位指挥官，指挥技能为【陨石召唤】：
    - 指定战场上任意一个 3×3 区域；
    - **2 回合后的我方阶段开始时**陨石落下，对区域内敌我所有单位造成 **7999 物理伤害**（必中，不暴击，不判朝向，经过地形、装甲等减免）；
    - 落下后，区域内没有单位的格子生成 **HP 1000 的陨石残骸**：挡住所有单位的移动和直射（不挡打向空中目标的直射），双方都可以攻击，HP 归零后消失；
    - 冷却 3 回合（下令后第 3 个回合才能再次使用），一场可以多次使用；
    - 预警区域和倒数在地图上可见。目前敌方 AI 不会主动躲避。
  - 指挥官系统与肉鸽模式的"指挥官（英雄无敌3式）"是两套设计，后者见下文。

## 二、肉鸽模式

> **详细设计已移到《肉鸽模式设计》（当前 v0.2）**，本节只保留最初的框架。已确定：HP 不跨战斗保留；出击上限起始 6，靠指挥型角色晋升、Feena 的「编制」技能和藏品解锁，最多 9；指挥官目前只有 Feena（英雄无敌 3 式成长），开局流派由「分队」决定（近卫分队、狙击分队……）；一局 3 层 + 终点，15–20 场战斗。

**定位**：参考《明日方舟》集成战略，尤其是第六期「沉沦者的黑流树海」的大地图探索结构，结合战棋战斗与英雄无敌3式的指挥官成长。

### 1. 指挥官（对应"分队"）
- 开局选择一位指挥官，决定整支部队的风格：初始加成、初始招募倾向。
- 指挥官不上场，作为全军成长层（参考英雄无敌3）：
  - **主属性**：小幅影响全军；
  - **二级技能**：例如后勤（全军移动 +1）、战术（开局可以调整布阵）、侦察（看到增援位置）；
  - **主动指令**：消耗指挥点数，相当于机战的精神指令。
- 每局开始时重置。

### 2. 机体等级：固定三档
| 档位 | 对应 | 内容 |
|---|---|---|
| Lv10 | 精英 0 | 基础武器 |
| Lv20 | 精英 1 | 解锁大招（传送斩、影凤凰、残月的余响、螺旋式打桩机、月华再生等） |
| Lv30 | 精英 2 | 大招强化（例如传送斩射程变为全图） |

- 每台机体只需要设计 3 套数值，敌人按层数和精英词缀变强，不随我方等级膨胀。
- **希望**（名称可以按世界观改）：招募和晋升都消耗希望。
- **招募券**：按战斗分类（近卫、尖兵、辅助、重装、修理、狙击……）发放。
- **临时招募**：支援机体直接是 Lv20 或 Lv30。
- **技能选择**（之后再做）：每台机体可以有多个大招方向，出战前或晋升时选择其一。

### 3. 局外惩罚：作战耐久
- 全队共享一个**作战耐久**值。
- 战斗中我方机体被击破会扣耐久，扣多少待定，可以按机体档位或体积区分。
- 耐久归零，这一局失败。
- 被击破的机体本身不会永久损失（待定：是否需要修理费用或冷却）。

### 4. 大地图：格子探索 + 行动力
- 每层是一张格子大地图，**走一格消耗 1 点行动力**。
- 节点类型（暂定）：作战、精英作战、事件、商店、休整、资源点、Boss。
- **追猎战**：行动力耗尽还没到达下一层，就触发一场更难的追猎战。打完恢复行动力，继续前进。教学关 1 的"被追击撤离"可以作为追猎战的模板。
- **快速移动**：类似「曲折密道」的传送点；类似「羽瞰点」的视野点，能揭示附近的未知节点。
- **污染区**（对应「实托邦」）：带负面效果的区域，例如负面地形、敌方增益；要找到并清除源头才能解除。

### 5. 藏品与零件
- **藏品**：全局修正器，直接挂在战斗系统的事件钩子上（阶段开始、伤害生成、减免管线、击破、行动结束等）。
- **零件**：地图探索中获得的道具，分三类：
  - 经济类：资源、货币相关；
  - 增益类：强化部队；
  - 移动类：行动力、地图移动相关。

### 6. 战斗内的地图资源
- 战斗地图上会有资源点，比如补给箱、氦三矿点，由尖兵类机体（如蕾卡）去获取，转化为局内货币、希望或零件。
- 这让尖兵的定位（高机动、高射程、低攻击）和肉鸽经济直接挂钩。

### 7. 难度与结局
- 难度分级逐级解锁，参考集成战略的保密等级，每级增加负面修正。
- 多结局。具体内容待定。

## 三、待定事项
- 剧情模式的经验 / 升级规则，以及奖励削减的具体比例。
- 作战耐久的数值，以及每种机体被击破扣多少。
- 希望的名称和获取量；招募 / 晋升价格表。
- 大地图的节点分布、行动力数值、追猎战规则。
- 指挥官的人选、主属性、二级技能和主动指令列表。
- 藏品和零件的具体列表。
- 战斗内地图资源的种类，以及尖兵获取它们的方式。
- 每台机体 Lv10 / Lv20 / Lv30 的数值表。
- 机体技能选择（之后再做）。
- 攻防公式的调整：装甲改为保底伤害还是比例减伤、属性要不要简化，这些在《战棋规则设计》里讨论。
