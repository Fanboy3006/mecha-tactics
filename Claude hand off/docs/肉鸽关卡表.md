# 肉鸽关卡表 v0.1（自动生成）

> 由游戏数据生成（试作版 v0.17，含分波），每次生成的内容都一样。用于逐关做精细设计：在这份表上改，或者直接告诉 Claude「把 ISW-1-N-3 改成……」。

## 编号规则

- 格式：**ISW-层-类型-序号**。例如 ISW-1-N-3：第 1 层可能出现的、普通作战类的第 3 关。
- 类型：N 普通作战、E 精英作战、G 出口守军、S 侵蚀源（第 2 层起）、C 追击战、F 终点。
- 每层的关卡池：N × 8、E × 3、G × 2、C × 2，第 2、3 层另有 S × 2；终点只有 ISW-4-F-1。共 50 关。
- 生成大地图时，每个战斗节点会从这一层、这一类的池子里抽一个编号（同一层尽量不重复），走近后能在节点上看到编号；追击战按局的种子从 C 池里选。
- **分波**：普通作战、侵蚀源、追击战 2 波，精英、出口守军、终点 3 波；第 2 波在第 3 回合到达，第 3 波在第 5 回合到达，清空当前敌人会让下一波提前出现。后续波次里的精英怪（以及 Boss）等级 +2。
- **随机部分**：「强化增援」侵蚀场会在第 1 波额外加敌人，这部分不在表里。
- 手工设计时也可以用 `waves:[{at:3, enemies:[...]}]` 覆盖第 2 波及以后的波次。
- **地图**：. 平原、f 森林、m 山地、w 水域、c 裂谷。我方从左侧出击，敌人在右侧。坐标是 (x, y)，从 0 开始。

## 怎么手工设计一关

在代码里的 `STAGE_OVERRIDES` 里按编号覆盖任意字段，没写的字段继续用自动生成的内容：

```js
'ISW-1-N-1': {
  name: '起始回廊',
  rows: [ /* 每行一个字符串，宽 26、高 16 */ ],
  enemies: [{t:'grunt', x:20, y:7}, {t:'sniper', x:24, y:3, lv:5}],
  affix: null,          // 或者 '护盾'、'强化' 等词缀名
  spots: [[2,8],[2,6]], // 我方出击点（可选）
  desc: '开局说明，会在第 1 回合弹出',
}
```
