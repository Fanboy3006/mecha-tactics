**价格 8 / 12 / 16 就是三档强度**：同一种效果常常做成三档。例：我方近战攻击 +15% / +25% / +35%；敌方防御 −12% / −21% / −30%。

## 二、值得借鉴的手法
1. **同效果三档**：一个效果出三件不同强度的，件数一下就够了，掉落、商店定价也简单。
2. **职业专属的固定配方**：每个职业几乎都有——
   - 「突破」：部署费用 −、生命 +（生存向）；
   - 一个纯增益：攻击 +25% 之类；
   - 一个**双刃**：近卫「防御 −40% 但攻击 +40%、攻速 +30」，狙击「生命 −40% 但攻击 +40%」，术师「生命 −40% 但法伤 +70%」；
   - 一个**场上叠层**：场上每有一名该职业，全队 / 敌人得到某效果（最多 8 层）。
3. **组合奖励**：「X 之手」只强化某几个分支职业，同时拥有对应的叠层藏品时再追加效果。拿齐一套会有明显回报。
4. **双职业协议**：「先锋 + 近卫」「重装 + 辅助」「医疗 + 狙击」「术师 + 特种」，编队里每有一名这两类干员，这两类的攻击 / 防御 / 攻速 +N。鼓励成对带人。
5. **构筑规则类**：改的是「怎么组队、怎么站」，不是单纯加数值。
   - 编队里每有一个不同职业的干员，全员攻击 +10%：鼓励杂编；
   - 距离伤害来源越远，敌人受伤越高：鼓励远程；
   - 只阻挡 1 名敌人时攻击 +100%；
   - 周围 4 格每有一名干员攻击 +20%：鼓励抱团；
   - 生命值越高攻击越高 / 越低攻速越快。
6. **敌方削弱**也是一大类：敌方攻击、防御、生命、攻速 −N%，或受到物理 / 法术伤害 +N%。
7. **经济和选择权**：商店 −50%；招募券、战利品多一个选项；每进一个非战斗节点 +2 源石锭；宝箱掉更多。
8. **资源换战力**：每有 5 源石锭全体攻速 +N。让「存钱还是花钱」成为抉择。
9. **永久成长叠层**：战后有概率全体攻防永久 +5%（最多 10 层）；每过一场紧急作战攻速永久 +5。
10. **套装**：国王系列、魔王系列，集齐 3 件效果大幅提升。
11. **低血量 / 极端条件爆发**：目标生命为 1 时全体攻击 +50%；把生命全部转成护盾、最大生命变为 1。都是高风险高回报。
12. **免费进阶按职业**：「X-典训」免费进阶一名该职业干员，和我们的职业券、希望晋升直接对应。

## 三、对应到我们游戏（待作者确认）
- 我们的 6 个职业：近卫、尖兵、辅助、重装、狙击、特种。每个职业做「突破 / 增益 / 双刃 / 叠层」4 件 = 24 件职业藏品。
- 双职业协议：近卫 + 尖兵、重装 + 辅助、狙击 + 特种，3 组。
- 稀有度用三档价格（源碳结晶），同一效果出三档。
- 「支援道具」可以对应成我们战场上的可放置物（地雷、补给站、掩体），和补给箱同一套中立单位机制。
- 「免费晋升」类对应职业券 / 希望；「目标生命」类对应坚守关的目标点。
