# 藏品设计 v0.1（第一批 50 件，待作者审）

作者 2026-10-05 已定：
- 藏品和零件**分开两套**：零件是大地图道具，藏品整局常驻、主要影响战斗；
- 第一批 **50 件**；名字**融合**原创和原作梗；
- 稀有度用**三档价格**：普通 8 / 稀有 12 / 传说 16 源碳结晶。

参考：《藏品参考·明日方舟集成战略》。

## 一、获取
| 来源 | 内容 |
|---|---|
| 精英战胜利 | 必得 1 件，三选一（普通 / 稀有） |
| 层底守军 / Boss | 三选一（稀有 / 传说） |
| 黑市 | 每次刷 2 件，按价格购买 |
| 事件 | 部分事件给藏品 |
| 补给箱 | 5% 概率给 1 件普通 |

- **掉落偏重**：70% 的概率从「当前分队对应职业」的藏品里出（月之国分队按辅助算），30% 全池随机。
- 同一件藏品一局只能拿一次。

## 二、数值说明
- 「伤害 +N%」「减伤 +N%」「命中 +N」「回避 +N」「暴击 +N」都和现有增益同一套算法，只是常驻不消失。回避 +20 ＝ 内部闪避 +10。
- 「HP +N%」「装甲 +N%」「移动 +N」「射程 +N」在每场战斗开始时加到出击机体上，不改动队伍里的存档数值。
- 「叠层」按本场**出击**的人数算，开战时定好，中途有人被击破不变。
- 射程 +N 不作用于地图炮、被动、指挥技能。

## 四、实现框架（给 DeepSeek）
1. 新文件 `src/js/23b-藏品.js`：`RELICS = {id:{name, tier:'普通'|'稀有'|'传说', price, cls?, desc, ...效果字段}}`，`RUN.relics = []`。
2. **常驻增益**：`buffSum` 改成同时加 `u.relicMods[k]`。开战时按 `RUN.relics` 给每台出击机体算一份 `relicMods`（dmg / red / hit / eva / crit / armorPct）；敌人的减益在 `onSpawn` 里算。
3. **属性类**（HP%、装甲%、移动、射程、援护次数）：在 `runBattle` 的 `afterStart` 里直接加到这场的出击机体上。
4. **条件类**（10、23、35、36、37、49）：挂在 `tfx` 或伤害管线里，按当场情况算。
5. **经济类**：黑市价格、补给箱、`deployCap()`、免费晋升，各改对应函数。
6. 获取：精英战结算、层底 / Boss 结算加三选一；黑市加藏品栏；补给箱 5%。
7. 界面：大地图右侧加「藏品」卡片；出击机体面板里显示「藏品加成」。
8. 测试：新增 `tests/relics.js`，至少验证常驻伤害加成、双刃的代价、叠层按出击人数算、黑市打折。
