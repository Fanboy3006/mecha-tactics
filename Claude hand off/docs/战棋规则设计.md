# 战棋规则设计 v2.4（测试版）

基于超级机器人大战 AP 的简化改版，未来向 roguelike 方向发展，并融合英雄无敌3式的英雄技能。本文件记录目前已敲定的规则，带「暂定」的数值以后会调整。关卡和关卡专用敌人的数值见《教学关设计》。

## 1. 地图
- 自由对战使用 40×40 的随机地图；教学关使用固定地图，尺寸跟着关卡走。
- 所有距离、射程一律按**菱形**计算（只算横竖步数，斜角算 2 步）。

| 地形 | 移动消耗 | 防御减免 | 闪避加成 | 阻挡直射 | 通行 |
|---|---|---|---|---|---|
| 平原 | 1 | 0% | +0 | 否 | 全部 |
| 森林 | 2 | 10% | +10 | 否 | 全部 |
| 山地 | 3 | 20% | +15 | **是** | 全部 |
| 水域 | 2 | 0% | +0 | 否 | 全部 |
| 裂谷 | — | — | — | 否 | **地面单位不能进入**，飞行可以 |

- 飞行单位移动消耗恒为 1，不享受地形防御和闪避加成。
- 飞行单位也会有不可进入的区域（之后定义）。
- 地图资源（之后讨论）：由尖兵类单位去获取。

## 2. 单位
- 机师和机体不拆分，一个单位带两个名字（机师名 + 机体名）。
- 单位有**体积**（如 1×1、2×2），移动、射程、落点都按占用的全部格子判定。大体积单位移动时按占用格子中最贵的地形计算消耗。
- 属性：HP、装甲、命中、回避、移动力、格斗、射击、技量、等级、朝向（v0.29 起命中 / 回避用机战式刻度，见第 7 节）。
- **标签**（为肉鸽做准备，目前只做展示）：势力、远近分类（近战 / 远程）、战斗分类。
- **战斗分类与定位**：

| 战斗分类 | 定位 | 现有单位 |
|---|---|---|
| 近卫 | 近身输出（全员有 DASH） | 雷萨 · B1、刹那 · CB1 等 |
| 尖兵 | 高机动、高射程、攻击力较低；勾引拉扯敌方部队，获取地图资源 | 蕾卡 · B2 |
| 辅助 | 增益、范围效果、回复（v0.17 起原「医疗」并入辅助） | Feena · M1、Iris · M3、库斯哈 · A5 等 |
| 重装 | 防御、援护（全员有援护防御） | 阿布拉德 · M2、卡嘉莉 · S2、布鲁克林 · A4、提耶利亚 · CB4、特洛瓦 · W3 |
| 狙击 | 站定开火的高命中远程重火力，主武器不能移动后使用（全员有援护攻击） | 洛克昂 · CB2、小太刀 Nagi · M4、希罗 · W1 等 |
| 特种 | 改变战场规则：强制移动、制造掩体、布置陷阱、完成地图任务 | 阿雷路亚 · CB3（强制移动）、提耶利亚 · CB4（掩体） |

- **势力覆盖（v0.26）**：每个势力至少 1 台重装、1 台狙击（影世界以后补人；秘银允许没有重装）。
- 以后可能在大类下再细分职业分支（类似明日方舟）。

## 3. 回合结构
- 我方阶段 → 敌方阶段 → 回合结束结算。
- 回合流程用事件钩子串起来（阶段开始、行动结束、攻击结算、击破、回合结束等），以后的英雄技能、遗物都挂在钩子上。
- 机体移动或传送后，必须先选择攻击或待机，才能结束回合。

## 3.5 操作与界面（测试版）
- **空格键快速操作**：
  - 没有选中机体时：**Tab / Shift+Tab** 在还没行动的我方机体之间切换光标（黄色虚线框，地图跟随，右侧显示它的情报）；按空格选中光标所在的机体；没有光标时，空格选中下一台还没行动的机体（按出场顺序循环）；
  - 全部机体都行动完时：弹出"是否结束回合"，再按空格确认结束，Esc 取消；
  - 选中机体、还没移动时：原地行动；
  - 移动后：如果有可以攻击的敌人，进入"选目标"状态（可攻击的敌人用红框高亮），点击敌人会自动选用对它期望伤害最高的武器，进入战斗预测，预测里仍然可以换武器；如果没有可攻击的敌人，直接待机；
  - 进入「选目标」时会自动**预选一个推荐目标**（白框和 ▶ 标记）：优先能击破的（按命中率加权），其次期望伤害最高的。再按空格直接选中它进入战斗预测，Tab / Shift+Tab 切换预选目标。所以一路按空格就是：选中机体 → 原地行动 → 选推荐目标 → 确认攻击，相当于半自动战斗；
  - 战斗预测 / 地图炮预测里：确认攻击。
- **WASD 改朝向**：移动后（指令面板、选武器、选目标时）按 W / A / S / D 把朝向改成上 / 左 / 下 / 右，效果和点方向键一样。待机时保持这个朝向；攻击时仍然自动转向目标。
- 移动后的指令阶段会自动用红框标出当前能打到的所有敌人。
- **Esc**：选中机体时，撤回这台机体本次所有还没确定的行动（移动、朝向、起飞 / 落地），并取消选中。传送、脱装变身、击破后的额外攻击这类已经发生的行动无法撤回，这时 Esc 把剩下的行动按待机处理。没有选中机体时，Esc 清除 Tab 光标；指挥模式下 Esc 取消指挥。
- 选中单位时显示头像：默认是按势力配色的原创徽章；也可以上传本地图片作为自定义头像（只保存在玩家自己的浏览器里）。
- **地图上的机体图标**（美术：已完成）：原创矢量素材，几何数据在 `art/mech-icons.js`（唯一源文件），由 `tools/build-src.mjs` 注入游戏。识别分三层：
  - **地面标记形状**表示敌我：我方是压扁的**方形**环、敌方是**圆形**环、中立物体（陨石残骸）没有标记（沿用原来「我方方块、敌方圆形」的读法）；
  - **机体剪影**表示战斗分类与个体，例如近卫是细高剑士、尖兵是低矮宽大的飞行框架、重装是超宽肩甲、狙击是一条斜贯整格的长枪；
  - **胸口核心颜色**表示战斗分类：近卫橙红、尖兵黄、辅助紫、重装蓝、狙击粉、特种青。
- **表现层：机体精灵比它占的格子大**（1×1 约 1.55 格宽、1.67 格高），底部对齐格子下沿、水平居中，允许盖住相邻格 —— 这样才有「站在格子上」的立体感，而不是被塞进一格色块里。绘制分三趟：① 地面标记（投影 + 占位环）→ ② 机体精灵（**按脚印下沿排序**，前面的挡住后面的）→ ③ 状态标记（HP 条、朝向、破防、飞行、机体名，永远在最上层、不会被机体压住）。
- 图标**不随朝向旋转**（缩小后会糊）。朝向标记画在**地面环的朝向那一侧**（不画在格子里 —— 机体比格子大，画在格子里会被挡住）；HP 条画在**机体头顶上方**。
- 已行动的机体整体换成灰调。机体有一圈**暗色外描边**，互相重叠时才分得开。
- 顶栏两个开关：**「机体名」**（显示短名，默认关）、**「网格」**（网格线和坐标数字，默认关）。网格默认关掉是有意的：常驻网格加坐标数字看起来非常像调试模式，去掉之后纯地形才像成品。
- 图标按**实际显示尺寸**（`TS × SC × 占地格数`）自动选细节等级：≤26px 用简化版（丢掉铆钉、细线，描边加粗 1.5 倍），≤46px 用中版，其余用完整版。原因见 `art/README.md` 第 8.2 节。
  - 还没画专属图标的机体（v0.17 新增的 25 台我方、16 种敌方）先**借用同战斗分类的原型剪影**，配色仍按自己的势力；敌方按体积借用量产机 / 战斗机 / 要塞 / 指挥舰。专属图标由 DSH 陆续补（清单见 `art/图标待办.md`）。
  - **护盾**（例如 U7 的 λ 力场）：机体外罩一圈青色光罩，血条前面多一段青色护盾条；护盾打空后光罩消失。**隐身**中的机体半透明。
- **声音**（v0.20）：编队界面和肉鸽开局放标题曲，肉鸽大地图放战略曲，战斗中按我方 / 敌方阶段切曲，场上有 Boss 级敌人或在终点关时放 Boss 曲，胜负时放号角；命中、未中、暴击、击破、护盾吸收、λ 觉醒、回复、预警、按钮都有音效。顶栏「声音」按钮或 **M 键**切换静音，选择会记在浏览器里。音乐和音效都是代码现场合成的原创素材（DSH 制作）。
- 攻击特效按武器类型区分：光束直射（光束）、实弹直射（曳光弹）、曲射（抛物线）、近战（斩击），命中爆炸、未中掠过、屏障护罩闪光。

## 4. 移动
- 每个单位有移动力，地形决定移动消耗。
- 友军可以穿过但不能停留；敌军不可穿过；没有控制区。
- **起飞 / 落地**：可变形的单位（目前是蕾卡）要在**移动前**决定这回合在天上还是地面；移动前可以来回切换，不占用移动力，移动之后就不能再改。落地要求脚下的地形允许地面单位进入。
- **传送**（雷萨专属指令）：移动到菱形 7 格内任意合法格（在地图内、没有单位、雷萨能进入），无视路径上的地形、裂谷和敌人。
  - 传送**代替本回合的移动**，传送后还可以调整朝向、攻击或待机，不能取消；
  - 每次使用反噬值 +25，反噬值低于 100 时才能使用；
  - 反噬值目前没有下降机制。

## 4.5 个人特技
- 每个角色有一个个人特技，**全部按被动技能设计**，**Lv10 解锁**。
- 剧情 / 教学关可以给个别角色提前开放特技（例如教学关 1 的雷萨需要用传送）。

| 角色 | 个人特技 | 效果 |
|---|---|---|
| 雷萨 | 门之力 | 即"传送"指令与反噬值（见第 4 节）。雷萨的背景已改为类似《机战 A》的阿克塞尔，特技之后还会改动 / 升级 |
| 蕾卡 | 游刃有余 | 行动结束时，本回合没用完的移动力每 1 点转为闪避 +5，持续到下一个我方阶段开始 |
| Feena | 月光共鸣（暂名） | 不能主动使用武器。我方阶段每次行动结束后，自动释放已解锁武器中**序号最高**的一把：Lv20 前是月光祝福，Lv20 起是残月的余响。所以前期是纯增益角色 |
| 阿布拉德 | 不动如山 | 本回合没有移动时，装甲 +30%，援护次数 +1 |
| Iris | 战地急救 | 修理友军时，额外给对方"物理减免 5%"（百分比减免阶段，只对物理伤害生效），持续到下一个我方阶段开始 |
| 洛克昂 | 狙い撃つぜ | 命中率超过 100 的部分，1:1 转为暴击率 |
| 阿雷路亚 | 超兵·哈雷路亚 | HP 低于 50% 时，命中 +20、暴击 +20 |
| 提耶利亚 | Veda 连接 | 变身为纳德雷的那一回合，命中 +30 |
| 刹那 | 我就是高达 | 每有 1 台敌机与自己相邻，命中 +10、闪避 +10（最多 +30） |

- "本回合没有移动"：指单位在自己阵营的阶段里没有移动或传送；到下一个自己阵营的阶段开始时重置。

## 4.6 强制移动与掩体（特种机制）
- **推击**：命中后把目标沿攻击方向（攻击者到目标的主方向）推开 N 格。
  - 撞到单位、障碍（不可站立的格子、力场壁）或地图边缘时停下；被推的单位受到 800 碰撞伤害，如果撞到的是单位，那个单位也受到 800。
  - 地面单位被推进裂谷，直接坠毁；飞行单位不会坠落。
  - 推完以后，目标不转身（v0.38；带正面装甲的除外）。
- **GN 墙**（掩体，来自提耶利亚变身纳德雷时脱下的外装甲）：在指定位置放一道 3 格宽的墙，方向与"放置者到中心格"的方向垂直。
  - 墙所在的格子地面单位、飞行单位都不能进入，推击撞上会停下；
  - 挡住所有直射，包括打空中目标；
  - 持续 2 回合，到期后在我方阶段开始时消失；
  - 只能放在空的、地面可通行的格子上（不能放在单位、裂谷或已有墙的格子上）。

## 5. 朝向、侧击与背击
- 每个单位有 4 个朝向：上、下、左、右。飞行单位也有朝向。
- **朝向变化**：
  - 移动后，朝向最后一步的方向；
  - 移动后（或传送后）的指令阶段可以手动调整朝向，待机时保持；
  - 发动攻击时，自动转到能打到目标的朝向并锁定（v0.38）；
  - ~~被攻击后转向攻击者~~：v0.38 起被打的一方不转身，只有带「正面装甲」的机体（铁壁）还会转身面向攻击者；
  - 雷萨的传送斩传送后面向目标；
  - 敌人移动后不攻击时，面向最近的我方单位。
- **受击面判定**：以目标朝向为前方，比较攻击者相对目标的"前后距离"和"横向距离"（2×2 单位用中心点）。
  - 前方距离 > 横向距离：正面；
  - 后方距离 > 横向距离：背面；
  - 其他情况（包括正好在斜线上）：侧面。

| 受击面 | 目标闪避 | 暴击修正 | 无视目标装甲 |
|---|---|---|---|
| 正面 | −0 | +0 | 0% |
| 侧面 | −10 | +10 | 25% |
| 背面 | −20 | +25 | 50% |

- 以上效果**只对这一击生效**，不留下持续状态（v0.16 起取消了侧击 / 背击的「破防」debuff）。
- 闪避扣到 0 为止：对不会回避（闪避 0）的目标，侧击 / 背击只剩暴击和无视装甲。
- 「W 系列」（拉米亚）被侧击 / 背击时不会被无视装甲。
- **破防**现在只由标记类技能附加（洛克昂 TRANS-AM 狙击、杨的激光标记）：目标所有防御按比例下降，到下一个我方阶段开始清除。
- 地图炮和被动技能**不暴击、不判朝向**。
- 浮游炮每段随机从 8 个方向攻击，按方向分别算正面 / 侧面 / 背面（正面 1/8、侧面 6/8、背面 1/8）。
- 援护防御一律按正面判定。
- 反击时攻击者已经面向目标，所以反击总是打在正面。

## 6. 武器
- 攻击类型：
  - **近战**：不检查视线。
  - **直射**：攻击者和目标之间不能有敌方单位或阻挡地形（目前是山地），否则目标不合法。友军不阻挡。视线按格中心连线判定，正好穿过角点时两侧只要有一侧通就算通。飞行单位开火时，山地同样阻挡。
    - **目标在空中时**：地面上的阻挡物（山地、地面单位）一律不算，视为中间没有阻挡；只有中间有**空中的大型敌方单位**（体积大于 1×1 的飞行单位）才会挡住。
  - **曲射**：无视阻挡，有最小射程。
  - **地图炮**：**必中，不暴击**，不能被反击，也不能用来反击。具体范围见各武器。
  - **辅助地图炮 / 修理**：对友军施加效果，不能用来反击。
  - **被动**：不能主动使用，满足条件时自动释放；必中，不暴击。
- **多段判定**：部分武器一次攻击进行多次命中判定，每段单独计算伤害并单独经过减免管线（除非武器无视减免）。所以固定装甲、能量屏障对多段攻击特别有效。
- **伤害类型**：物理 / 光束 / 特殊。
  - 物理、光束：会受到对应的弱点 / 抗性 / 减伤影响（如光束涂层、光束反射装甲）。
  - **特殊**：除了**护盾类效果**（能量屏障、λ 力场、护盾值）以外，什么减免都不吃（装甲、地形、防御姿态、抗性、减伤全部无视）。
  - 带「无视防御」的武器（传送斩、螺旋式打桩机）连护盾也无视。
- **多重锁定**：选择射程内最多 N 台敌机逐一攻击，目标不能反击、防御或回避。
- **浮游炮**（v0.29 削弱）：我方（卡嘉莉 DRAGOON、拉克丝超级 DRAGOON）8 段，普通敌人（浮游炮母机）3 段，只有 Boss 级敌人才有 8 段以上；原来是一次攻击 16 段，每段从 8 个随机方向攻击，目标闪避减半，不需要视线，不附加破防。
- **地图炮的形状**：冲刺型（冲到第 5 格，攻击沿途 4 格，如影凤凰）、直线型（不移动，直线 N 格）、范围型（以自身为中心半径 N）。带「敌我识别」的只打敌机，其余会误伤友军。
- **CD 与次数**：取消 EN。武器按冷却回合和使用次数计算，没有特别说明时为 0 CD、无限次数。CD n 表示使用后要等待 n 个己方回合。
- **移动后使用**：除影凤凰外，所有武器都可以在移动后使用。
- **等级解锁 / 等级强化**：部分武器到指定等级才能使用，或在指定等级获得强化（如射程变化）。

## 7. 命中与暴击
- **基础暴击**：10%，刹那额外 +15%（v0.30）。
- **v0.29 机战式刻度**：
  - **命中**（驾驶员属性）：我方按战斗分类初始值——狙击 180、尖兵 170、近卫 / 特种 165、辅助 160、重装 150；敌人默认 160。Lv20、Lv30 晋升各 +10。
  - **回避** = 100 + 2 × 闪避（例：闪避 15 → 回避 130，蕾卡闪避 40 → 回避 180）；不会回避的单位显示「—」。
  - 命中率 = 武器命中 − 30 + (攻击方命中 − 目标回避) ÷ 2 + 命中加成 + 特技 / 光环 − 地形闪避 − 闪避加成 + 朝向闪避削减。
  - 等价写法（内部实现）：武器命中 + (命中 − 160) ÷ 2 − 目标闪避 − ……；地形、光环、朝向里写的「闪避 ±N」仍按命中率百分点算（相当于回避 ±2N）。
- 旧写法（v0.28 以前）：命中率 = 武器命中 + 命中加成 + 特技 / 光环 −（目标闪避 + 闪避加成 + 地形闪避 − 朝向闪避削减）。
- 选择「回避」时，敌方命中率减半。部分敌人不会回避。
- **闪避疲劳（v0.29 起全员通用）**：所有会回避的单位，同一回合内每完全闪避一次攻击，闪避 −10（回避 −20），可累计，下一个我方阶段开始时恢复。面板「回避」后面会显示「疲劳 −N」。
- "完全闪避"指这次攻击没有任何命中（多段攻击全部未中才算）。
- 暴击率 = 10% + 武器暴击修正 + 朝向暴击修正 + 特技 / 增益加成（暂定）。暴击伤害 ×1.2（ZERO 系统 ×1.5）。

## 8. 伤害（先判定，再减免）
1. 命中判定；
2. 生成伤害：(威力 + 格斗或射击 × 5) × 暴击倍率 × (1 + 弱点% + 特技增伤% + 增益增伤%)；
3. 减免管线，按顺序结算（第 2、3 步先乘以破防系数）：
   1. 无效化类（能量屏障）；
   2. 百分比减免（地形、正面装甲、GN 全盾、防御姿态、抗性、光束反射、特技 / 增益减伤）；
   3. 固定值减免（装甲，扣完最低 10 点；侧击 / 背击无视一部分）；λ 力场（每阶段前 2 次各 −3000）；
   4. 护盾值（先于 HP 吸收，己方阶段开始时回满）；
4. 扣血，触发受伤、击破事件。
- **无视防御**的武器跳过整条管线（包括屏障和护盾）。
- **特殊伤害**只经过护盾类（屏障、λ 力场、护盾值）。

### 8.1 弱点与抗性（v0.16）
- 每种敌人带一张弱点 / 抗性表，正数是弱点（生成阶段增伤），负数是抗性（百分比减免阶段，受破防削弱）。
- 可以针对的条件：光束、物理、近战、直射、曲射、范围（地图炮 / 被动 / 指挥技能）、背面、暴击、多段（每段）、反击。
- 敌人情报面板会列出弱点和抗性；战斗预测的计算过程会写出生效的条目。

## 9. 反击与援护
- 敌方攻击时，我方选择反击、防御（伤害 −50%）或回避（命中减半）。
- 反击按正常规则消耗 CD 和次数；射程不够或没有视线时不能反击。
- **援护防御**（所有重装）：在敌方阶段友军被攻击时，只要援护者用移动力能走到它旁边（**援护范围 = 移动力覆盖范围**，v0.26；援护时不实际移动），就可以选择代为承受，并自动进入防御姿态（不能反击），一律按正面判定。每个敌方阶段 2 次（不动如山 +1）。援护挡下的是**一整轮**：对方随后的援护攻击也打在援护者身上。
  - **进攻援护**（卡嘉莉）：援护防御在我方阶段也能用。援护范围内的友军攻击后被反击时，可以代为承受那次反击；我方阶段开始时也重置为 2 次。
- **援护攻击**（所有狙击，以及敌方的狙击机、浮游炮母机）：己方阶段同伴主动攻击、目标没被击破时，可以跟着用一个武装攻击同一个目标，目标不能反击。每台每回合 1 次。
  - 我方会弹窗询问，第一个按钮是伤害最高的武装，所以一路按空格就会援护；敌方自动援护。
  - 地图炮、锁定类、被动不能用来援护。
- **DASH**（所有近卫）：主动攻击击破敌机后，获得 3 点移动力和一次额外攻击，可以先移动再攻击，也可以原地攻击。每回合 1 次；刹那的特技「DASH+1」让上限变成 2 次，一回合最多行动 3 次。DASH 之后的攻击再击破，可以继续触发，直到用完次数。

## v0.36 控制区（ZOC）
作者 2026-10-06 定。
- **控制区**：敌方机体上下左右相邻的格子。大体积机体按整个身体外围算。双方都适用。
- **效果**：走进敌方控制区的格子就要停下，剩下的移动力作废。两台敌人之间只隔一格的缝因此钻不过去。
- **起点已经在控制区里**：可以正常离开；离开后再走进控制区，照样要停。
- **飞行单位**：会被地面单位的控制区拦住。
- **没有控制区**：
  - 空中的机体（落地后才有）；
  - 召唤物（新标签 `summon`；目前是无人机、蜂群无人机）；
  - 中立单位（陨石残骸、补给箱）。
- **无视控制区**：
  - 尖兵（职业特性「渗透」）；
  - 隐形机；
  - 传送不走路，本来就不受影响。
- **重装不加额外的封锁效果**（作者否决）。
- **界面**：选中机体时，移动范围里画红框的格子是控制区，走到那里就得停。
- **AI**：
  - 移动时遵守控制区；
  - 算「离哪个我方最近」时不管控制区，所以被挡住时仍朝原目标绕路前进。
- **代码**：`11-移动.js` 的 `zocSet / inZoc / reach(u, cap, {zoc})`；测试 `tests/zoc.js`。

## v0.37 伤害公式
作者 2026-10-07 定。

**伤害 =（武器威力 − 装甲）×（1 +（攻击能力值 − 防御值）/ 100）**

- 命中后最少 10 点：后面那个系数可以是 0 或负数，结果照样保底 10。
- 公式里每一项都可以挂加成。**所有原来的百分比加成都归到某一项里**，不再在最后单独乘。

| 项 | 内容 |
|---|---|
| 武器威力 | 武器威力（含晋升强化）× 弱点 / 抗性（如光束弱点 +30% = 光束武器威力 ×1.3；抗性受破防削弱）× **暴击 ×2**（零式 ×2.5，赌神 ×4） |
| 装甲 | 装甲（含装甲 % 增益、藏品、敌方装甲削弱）× 破防；侧击 / 背击无视 25% / 50%。**多段攻击每段都扣** |
| 攻击能力值 | 武器对应的属性：**格斗 / 射击 / 觉醒**，可以写「格斗+觉醒」相加；× **大招倍率**（`statMul`）。再加：特技、增益、藏品、压制杂兵（+100）、肉鸽加成。原来的「伤害 +N%」现在都是「攻击能力值 +N」 |
| 防御值 | **防御**属性 + 地形（森林 +10、山地 +20…）、正面装甲 +50、GN 全盾 +30、防御姿态 +50、光束反射 +50、λ 驱动器 +60、物理减免、减伤类特技 / 增益 / 肉鸽。原来的「减伤 N%」现在都是「防御值 +N」。整体 × 破防 |

- **特殊伤害、无视防御**：装甲和防御值都按 0。
- **固定伤害**（雷萨传送斩、残月余响、陨石召唤）：不加属性，也不算防御属性，只算场面上的防御加成。
- **公式算完后**（门槛 / 吸收，不是百分比）：能量屏障（≤2500 无效）→ λ 力场（−3000）→ 护盾吸收。
- **属性**：
  - 去掉技量（原来只用于显示）；新增觉醒、防御，每级 +2，晋升 +25；
  - 防御初始值：我方按职业，敌方按梯队；
  - 觉醒暂时全员 100。
- **武器面板**显示「攻击力」= 武器威力 ×（1 + 攻击能力值 / 100），即打 0 装甲、0 防御目标的不暴击伤害。鼠标悬停能看到原始威力和用哪项属性。
- **赌神**（响介，替换「全押」）：未命中的攻击有 50% 直接改为一次命中的暴击，暴击威力 ×4。多段攻击每段都判定；战斗预测里会显示赌神伤害，期望值也算进去。
- **换算**：源数据里的威力还是旧公式的数值，开局时换算成新公式的威力（`30b` 的 `convWeapons`）。
  - 参照点：我方 Lv10 打 Lv2 杂兵；敌方 Lv5 打 Lv10 我方平均（装甲 600、防御 103）。
  - 测算：Lv10 我方打杂兵的平均伤害和旧版相差 1% 以内（近卫因压制杂兵改成 +100 能力值，比旧版低约 10%，仍然一刀一个）。
  - 新公式下，敌人打我方时，低防御的狙击、尖兵比以前多吃约 30–40%，重装少吃。
  - 暴击从 ×1.2 变成 ×2，期望伤害整体略升。
- 测试：`tests/formula.js`。

## v0.38 朝向范围与压制射击
作者 2026-10-07 定。
- **攻击范围跟着朝向走**（参考明日方舟）：
  - 默认形状：近战 = 前方 + 左右两侧（不含背后）；远程 = 只有前方（前进方向至少 1 格），距离仍按射程；
  - 武器可以写 `pat:[[前, 侧], …]` 自定义形状（以朝右为准：前 = 向右几格，侧 = 向下几格，负数向上）。写了 `pat` 的武器不再看射程。具体武器的形状交给角色对话。
- **自己回合**：
  - 移动结束后定朝向（默认最后一步的方向，W A S D 或方向键可改）；
  - 主动攻击时转向没有额外消耗，打出去时**锁定**在能打到目标的朝向：当前朝向能打就不转，其次正对目标，再其次任意一个能打的；
  - 一路按空格攻击，会自动转到合法朝向。
- **敌方回合**：只能反击**当前朝向范围内**的敌人，反击时不转身。被打的一方也不再自动转身（带正面装甲的除外）。
- **压制射击**（狙击职业能力）：
  - 敌方阶段，敌人一格一格移动；第一个从范围外走进狙击当前朝向攻击范围的敌人，挨这台狙击一发；
  - 每台狙击每个敌方阶段 1 次；目标固定是第一个进来的，不能选；用对它期望伤害最高的、能用来反击的武器（会消耗弹数和冷却）；
  - 挨打的一方不能反击，打完继续走（被击破就停下）；
  - 狙击原来的「援护攻击」保留。
- **界面**：
  - 选中机体后（指令面板、选武器、选目标时），橙色格子是这个朝向下的反击范围；狙击用亮黄色，同时也是压制射击的射界；
  - 点一下敌人，能看到它朝向下的范围（红色）。
- **背击**：加成不回调（作者确认）。背后既吃背击加成，又不能反击，是绕后的核心回报。
- 测试：`tests/facing.js`。角色试炼的贪心机器人不会管朝向，能打完的关从 27 个降到 24 个，这在预期之内。
