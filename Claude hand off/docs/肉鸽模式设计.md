# 肉鸽模式设计（草案 v0.4 · 已有试作版）

> 参考：《明日方舟》集成战略第六期「沉沦者的黑流树海」。
> 本文先定**机制骨架**，数值都是起步值，用来试玩后再调；名词暂时不替换。
>
> **世界观**：各个平行宇宙被扭曲在了一起，形成一座**混沌迷宫**。玩家在迷宫里招募来自不同宇宙的角色（影世界、月球王国、天人、克莱因派、预防者、ATX、秘银……）组队战斗、向深处推进。所以招募谁都说得通，跨作品同队也合理。每一层航区就是迷宫的一段。
> 战斗规则沿用《战棋规则设计》，本文只讲局内大地图、经济、成长和局外部分。

## 1. 一局的结构

- 一局有 **3 层航区 + 第 4 层终点**。终点只有一场 Boss 战，根据收集的条件会进入不同的结局，详见第 9 节。
- 每层的航区图是 6×4 网格，约 15–20 个节点，其中有几个空节点。视野 3 格，其余是迷雾。
- **推进剂**：
  - 每层开始时补满，起始上限 **10**；
  - 走进一个相邻节点消耗 1。沼泽、碎石带这类带地形标记的节点消耗 2；
  - 走回已经清理过的节点也要消耗（所以路线要规划）；
  - 推进剂归零、还没走到出口时，立刻触发**追击战**。
- **离开本层**：
  - 走到「出口（无守军）」直接进入下一层；
  - 「出口（有守军）」要先打一场作战；
  - 打赢追击战也会进入下一层，但是从下一层的「不利起点」开始（比如被包围的位置）。
- **作战耐久**（这一局的生命值）：
  - 起始 **10**；
  - 我方机体被击破**不扣**耐久；
  - 作战失败时，剩余敌人每 1 台扣 1 点；只要没归零，照常结算奖励，节点变成空节点；
  - 耐久归零，这一局失败；
  - 休整点、部分事件和藏品可以回复耐久。

## 2. 分队（开局选择）

开局选一个分队，分两类：

### 2.1 职业分队（6 个）
- 近卫分队、尖兵分队、辅助分队、重装分队、狙击分队、特种分队（「医疗」已并入辅助）。
- **效果只有一个：开局送一名该分类的 Lv20 角色**，从该分类全部角色里任选，这名角色不花希望。
- 没有指挥官，也就没有指挥点和指令。

| 分队 | 候选池（当前） |
|---|---|
| 近卫分队 | 雷萨、刹那、史黛拉、希尔妲、迪奥、五飞、响介 |
| 尖兵分队 | 蕾卡、露娜玛丽亚、阿莎琪、诺茵、拉米亚、杨 |
| 辅助分队 | Feena（非月之国分队时）、茱莉、卡托尔、真织、Iris、库斯哈 |
| 重装分队 | 阿布拉德、卡嘉莉、布鲁克林 |
| 狙击分队 | 洛克昂、志保、艾克赛琳、克鲁兹、克鲁佐 |
| 特种分队 | 阿雷路亚、提耶利亚、拉克丝、希罗、特洛瓦、杰克斯、宗介 |

### 2.2 月之国分队（Feena）
- Feena 担任指挥官，**不出场**，用下面 2.5 节的英雄无敌 3 式成长。
- 不送 Lv20 角色，换来的是一整局可以成长的指挥官和指令。
- 选月之国分队时 Feena 是指挥官、不在招募池里；**选其他分队时 Feena 可以作为精锐角色被招募**。

## 2.5 月之国分队的指挥官：Feena（英雄无敌 3 式）

只有选择月之国分队时才有指挥官。Feena 不出场，作为全军的成长层。

**主属性**（4 项，每次升级随机 +1 项，二级技能可以影响倾向）：
- **攻击**：全军伤害 +2% / 点；
- **防御**：全军减伤 +2% / 点；
- **统率**：陨石召唤等指令的威力 +5% / 点；
- **知识**：指挥点上限 +1 / 2 点。

**升级**：
- 每场作战胜利获得经验，精英、Boss 战更多。
- 每次升级从 2–3 个**二级技能**里选 1 个，每个技能有初级、中级、高级三档；最多学 6 个二级技能。

| 二级技能 | 作用（初 / 中 / 高） |
|---|---|
| 后勤 | 全军移动 +0 / +0 / +1；推进剂上限 +1 / +2 / +2 |
| 领航 | 推进剂上限 +2 / +3 / +4 |
| 侦察 | 大地图视野 +1；中级起能看到节点标记；高级能看到追击战的敌人构成 |
| 战术 | 战前布阵范围扩大；高级允许第 1 回合先调整朝向 |
| 炮术 | 地图炮、范围攻击伤害 +10% / 20% / 30% |
| 电子战 | 敌方命中 −5 / −10 / −15 |
| 编制 | 出击上限 +0 / +1 / +1，晋升 −1 希望（高级） |
| 理财 | 每层开始时获得源碳结晶 3 / 6 / 10 |
| 月光加护 | 陨石召唤冷却 −0 / −1 / −1，范围 3×3 / 3×3 / 5×5 |

**主动指令**：
- 每场战斗开始时获得指挥点（基础 3 + 知识加成），下达指令消耗指挥点，相当于机战的精神指令。
- 起始只有【陨石召唤】（沿用剧情模式，消耗 3）。
- 升级时可能学到新的指令，例如：
  - 必中：1 台机体本回合必中；
  - 闪避：1 台机体下一次必定闪避；
  - 铁壁：1 台机体减伤 50%；
  - 再动：1 台已行动的机体再行动一次；
  - 月光祝福：小范围加命中、闪避。

## 3. 部队：招募、等级、出击

- **等级固定三档**：Lv10（基础）/ Lv20（解锁大招）/ Lv30（大招强化）。敌人随层数和精英词缀变强，不随我方等级膨胀。
- **希望**是唯一的招募 / 晋升资源，没有招募券：
  - 开局 **8** 希望；
  - 普通作战胜利 +2，精英作战 +3，出口守军、侵蚀源 +4；
  - 部分事件、自然物出售也能换希望。
- **招募**：
  - 每场作战胜利后都有**一次招募机会**：随机给 3 个候选（跨分类），花希望招募其中 1 个，或者放弃（放弃返还 1 希望）；
  - 新招募的角色是 Lv10；
  - 招募站节点额外给一次机会，候选固定为同一分类。
- **晋升**：Lv10→20、Lv20→30，消耗希望，价格按角色档位定（见 3.1）。
- **队伍上限**：同时持有 12 名角色（暂定），满了以后可以遣散。

## 4. 战斗节点（和战棋战斗怎么接）

- 每场作战从**关卡模板**里抽取：
  - 地形模板，有裂谷、山脊、水域等主题；
  - 敌人组合，从 28 种敌人里按层数抽，每层有自己的「主题弱点」，比如第 1 层多光束涂层机，让玩家意识到要带实弹；
  - 胜利条件：全歼 / 撤离 / 守住 N 回合 / 击破指定目标。
- **精英作战**：敌人带词缀，例如「护盾 +3000」「光束抗性」「回合开始回血」「绕背」。奖励更好，必出藏品选择。
- **HP 不跨战斗保留**（已确定）：每场都满血开打，冷却、次数也重置，只用作战耐久惩罚。
- **战场资源点**：地图上的补给箱、源碳结晶矿点，由机体走过去拾取，尖兵移动力高，最适合。
  - 拾取后战后结算为源碳结晶 / 希望 / 零件。
  - 这让尖兵（蕾卡、杨、诺茵等）在肉鸽里有经济价值。
- **作战评价**：在回合上限内完成、没有机体被击破等条件，可以额外奖励希望。

## 5. 大地图节点类型

| 节点 | 说明 |
|---|---|
| 作战 | 普通战斗，奖励源碳结晶、希望，三选一零件 |
| 精英作战 | 带词缀的敌人，奖励藏品选择 |
| 事件 | 文字事件，选项可能涉及耐久、推进剂、藏品交换 |
| 黑市 | 买卖零件、藏品；可以把自然物卖掉或「投资」到下一层 |
| 休整 | 回复作战耐久 +2，或下次晋升 −1 希望，二选一 |
| 招募站 | 额外一次招募机会，候选同一分类 |
| 中继站 | 揭开周围 2 圈的迷雾 |
| 废弃隧道 | 成对出现，互相传送，不消耗推进剂 |
| 补给站 | 推进剂 +3 |
| 侵蚀源（第 2 层起） | 一场特殊作战，打赢后解除本层的侵蚀场 |
| 出口（无守军 / 有守军） | 进入下一层 |
| 宝藏 / 遗迹 | 特殊奖励，通常在死路或迷雾深处，诱惑你多花推进剂 |

- **节点标记**：节点左上角的小标记会改变节点内容，例如「伏击」（敌人先手）、「增援」（多一波敌人）、「丰收」（奖励翻倍）。部分藏品能添加、去除或者看穿标记。

## 6. 侵蚀场（对应实托邦）

- 从第 2 层开始，每层随机一种**侵蚀场**全局效果，例如：
  - 「过载侵蚀」：我方所有机体处于**过载**状态（见下），无法解除；
  - 「感应迷雾」：直射射程 −2；
  - 「重力异常」：飞行单位必须落地；
  - 「强化增援」：所有作战多一波增援。
- 侵蚀源藏在本层迷雾里，摧毁后解除，并给奖励。是否去摧毁，就是在推进剂上的取舍。
- **过载**（新状态，对应狂躁）：伤害 +30%，但每次攻击（包括反击）自身受到 5% 最大 HP 的伤害，无视护盾。高频攻击的机体（多段、多重锁定、连斩）会收益最大，也最危险。

## 7. 零件与藏品

### 7.1 零件（沿用明日方舟黑流树海的设定）

- 零件放在**零件箱**里，容量有上限（初始 4 格，暂定）；在黑市花 6 源碳结晶「空间租赁」可以扩容。
- 零件可以在黑市出售。
- 三类：

**自然物（理财）**：持有期间估价会变化，在黑市卖出换源碳结晶。
| 零件 | 效果 |
|---|---|
| 血蕈 | 每次作战后估价 +2 |
| 浪花 | 每次移动后估价随机变化 |

**概念体（自动触发）**：满足条件时自动生效。
| 零件 | 效果 |
|---|---|
| 河谷祭祈 | 某些分队的初始携带品（效果待查） |

**加工品（有使用次数，主要用来移动）**：

### 7.2 藏品（占位）

- **暂不设计**，只预留接口：藏品是全局被动，挂在战斗系统的事件钩子上（伤害生成、减免管线、阶段开始、行动结束、击破等），代码里已经有对应的 Hooks。
- 来源：精英作战、侵蚀源、宝藏 / 遗迹、黑市。

## 8. 敌人的新行为（对应变身、后撤步）

- **形态切换**：HP 降到 50% 时换一套武器和弱点，例如从「光束抗性」变成「物理抗性」，逼玩家换武器。
- **绕背**：部分精英敌人受到攻击后瞬移到攻击者背后，利用朝向系统打我方背面。
- **追击战的追兵**：沿用教学 1 的追击炮车模板，追兵每回合逼近，只能边撤边打。

## 8.5 成长曲线（一局 15–20 场，靠成长撑住节奏）

一局的长度不压缩，靠每一层都有明显的成长节点来撑住节奏：

| 阶段 | 典型状态 | 成长来源 |
|---|---|---|
| 开局 | 职业分队：1 台 Lv20 + 用 8 希望招的 1–3 台 Lv10；月之国分队：Feena 指挥 + 2–4 台 Lv10。出击 6 | 分队、开局希望 |
| 第 1 层末 | 5–6 台，1–2 台 Lv20（大招上线），Feena 2–3 级 | 每战一次招募机会、第一次晋升 |
| 第 2 层末 | 7–8 台，主力 Lv20、1 台 Lv30，出击 7 左右，5–7 个藏品，侵蚀场的取舍 | 精英作战、黑市、指挥型角色晋升 |
| 第 3 层末 | 9–10 台，2–3 台 Lv30，出击 8–9，形成流派（藏品 + 分队 + 二级技能的组合） | 隐藏节点、遗迹、侵蚀源奖励 |
| 终点 | Boss 战 | — |

- 每层的敌人强度按「这一层末的预期成长」来定。前半层偏简单，后半层和出口守军偏难。
- 每场作战胜利都给一次招募机会；每层至少保证 1 次晋升机会和 1 次藏品选择，避免运气太差卡死。

## 9. 结局与难度

- **多结局**：普通结局打赢第 4 层 Boss 即可；隐藏结局需要额外条件，例如每层都摧毁侵蚀源、携带特定藏品。
- **难度分级**：通关后逐级解锁，每级叠加一个负面修正，例如敌人 HP +10%、推进剂上限 −1、作战耐久 −2。

## 10. 局外成长树（占位）

- **暂不设计**，只占位。方向参考黑流树海的「种子培育」：
  - 局内带回资源，在基地的成长树上投入；
  - 解锁内容：起始希望、零件箱容量、新分队、新指挥官、藏品 / 零件进入奖池、难度等级；
  - 总量设上限，避免数值膨胀。

**已实现**
- 分队选择：
  - 月之国分队：Feena 指挥，开局 3 张随机分类的招募券（v0.22 起不再额外 +4 希望，所有分队开局希望都是 8）；

- **部队等级**：经验来自作战（普通 5、追击 7、精英 8、守军 / 侵蚀源 9）和事件。升级所需累计经验依次为 8 / 18 / 30 / 44 / 60 / 78 / 98 / 120 / 144 / 170，每升 1 级希望 +5。**希望只从这里来。**

  - 固定有：起点、2 个出口、4 场作战、1 场精英、黑市、2 个事件、补给站；第 2 层起还有侵蚀源；
  - 有空位时再放：遗迹（优先放在死路）、休整、招募站、中继站、废弃隧道；
  - 剩下的都是空节点，约 3–6 个，只能路过。

  - 终点失败但耐久没归零，也算通关。

## 关卡设计方向（作者 2026-10-05 定；v0.32 已实现第一版，见下一节）
- **少而强**：敌人数量减少、单体数值提高；AI 简化成几种固定套路（冲锋：直扑最近目标 / 炮台：原地用曲射 / 守卫：守一个区域），让玩家能预判。
- **每关一道考题**：围绕前面教过的机制出题——推拉入坑、贴身封住曲射（曲射有最小射程）、正面装甲逼侧击 / 背击。
- **允许数值碾压**：练度高了可以硬打过去，考题是捷径不是唯一解。
- **目标类型多样化**：
  - 全歼（现有）；
  - **坚守 N 回合**：敌人不断刷新，撑到回合数就赢；敌人存活不扣目标生命值；
  - **突破**：让指定角色到达目标地点；
  - **斩首**：敌人不断刷新，击破固定地点的几个中立单位 / 敌人就赢。
- 从第一层普通战斗开始改。
