# art/pixel —— 像素画方向（美术对话，2026-10-08）

作者 10-08 定的方向：**Q 版像素，接近机战 A**。这里是原稿和工具，还没接进游戏。

## 分层
| 档位 | 规格 | 做法 |
|---|---|---|
| 大众脸 / 杂兵 | 16×16 | `grunt16.py`：手写调色板字符串，正面 / 背面写左半边自动镜像，侧面整行写（朝左 = 镜像） |
| 势力普通档 | 16×16 | `parts.py` + `compose.py`：势力头型 × 职业机身拼装；`faction16_render.py` 出表 |
| 精锐 | 24×24 | `elite/*.py`：材质图（每个字符一种材质），`mm.py` 自动描边、按左上光源打光；站在格子里时头和武器超出格子往上长 |

## 精锐（作者 10-08 确认「够用」）
雷萨（最满意）、Feena、刹那、拉克丝、希罗、响介、宗介。每台一个原创轮廓 + 一个动态招牌特效（特效在样张页的 `eliteFX` 里，用代码画）。
- 原则：**不复刻原作机体造型**（项目规定）。希罗的翼做成直边分节机械翼、长炮平端，不画原作的招牌姿态。
- 大部分角色用白脸，只有雷萨、响介保留面罩。

## 出图
- `cd elite && python3 sheet.py ../out/精锐.png rasa feena setsuna lacus heero kyosuke sousuke`（四向总表，6 倍放大）
- `out/<名字>_<front|side|back>.png` 是 1 倍原图，朝左 = 侧面镜像。
- `像素样张.html`：发给作者看的样张页（地图、四向、势力、精锐、战斗演出），素材都内嵌。
