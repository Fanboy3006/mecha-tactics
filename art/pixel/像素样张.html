用战术挑战 CH-01 的真实地形和开局站位，换成 Q 版像素画风重画。地块和特效来自免费 CC0 素材（Ninja Adventure、Aim studios），机体是原创像素画。点地图上任意机体，可以让它转向，检查四个朝向能不能一眼看出来。

方形底环 = 我方 圆形底环 = 敌方 血量 护盾（第二条，先扣） 特殊力场（只有这类才画光圈）

四个朝向

从左到右：朝下（面向镜头）看得到发光的护目镜和胸口核心；朝右 / 朝左是侧面，武器指向前方；朝上（背对）只看到头盔后脑和背包推进器（橙色）。胸口核心的颜色沿用现在的职业色。

精锐：七台招牌机

精锐不再靠换色区分，每台一个只属于自己的原创轮廓 + 会动的招牌特效。画布从 16px 放大到 24px，站在格子里时头和武器会超出格子往上长，一眼就能从杂兵堆里认出来。下面的小地图是实际比例。

小地图（每台隔一格站）：上排 7 台精锐，下排是同一套 16px 的大众脸和杂兵，对比大小和存在感。

骨干（20px + 一个专属部件）

骨干比杂兵大一圈（20px），共用一套机身，每台加一个只属于自己的标志物，不配动态特效（特效留给精锐）。配色跟势力走。阿布拉德改成了重型坦克（2×2，32px）；提耶利亚加了变身形态纳德雷；杰克斯暂时拿掉。

七个势力（普通档的底子）

每个势力一套原创的设计语言：配色沿用现在的势力色，头型和眼睛颜色各不相同；机身按战斗分类（近卫细长带剑、尖兵背翼加脚底推进、指挥肩天线加披风、重装宽肩、狙击长枪、特种双肩导弹舱）。格子下面是这一格的角色。不复刻原作机体造型，角色的个性化以后在这套语言里加。

头型：影世界 = 后掠双角 + 单条眼光；月球王国 = 骑士盔 + 白羽冠；天人 = 前掠耳鳍 + 绿眼；卫星国防军 = 羽毛天线 + 圆脸；预防者 = 金色高冠；ATX = 方盒头 + 橙色目镜；秘银 = 后伸天线 + 宽目镜。灰色半透明的格子是这个势力暂时没有的职业，画出来只为看整套是否统一。

请你看这几点

  1. 骨干：16 台的标志物哪些不对味？想换成什么？
  2. 精锐：七台招牌机够不够「一眼认出」？哪台最不满意？骨干要不要也做到这个程度，还是介于精锐和普通之间？
  3. 势力：七个势力站在一起分得清吗？哪个势力的头型你想换？
  4. 画风方向：16px、GBA 掌机这种颗粒感，你满意吗？还是想要更细的 24px（细节多、但离机战 A 远一点）？
  5. 朝向：不开箭头，单看机体能分出四个方向吗？
  6. 地形：草地、树林、岩石、绝壁（灰绿台地）、裂谷（黑色深坑）够不够好认、够不够好看？
  7. 护盾：血条下面加一条青色护盾条，这个读法行不行？
  8. 战斗演出：节奏（大约 2 秒）合适吗？要不要能一键跳过？
